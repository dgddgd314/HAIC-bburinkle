# Pencil source and license

This asset is converted from `~/Downloads/pencil/pencil.obj` with its original
`textures/blinn1_baseColor.png` texture.

The work is based on [Pencil](https://sketchfab.com/3d-models/pencil-8b0f41f8b2dc475ca0083f381abc54bd)
by [jablazinb](https://sketchfab.com/jablazinb), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The visual mesh is scaled to about 28.9 cm and rotated so its long axis is local X.
Collision uses a grasp-stable capsule of the same length. Runtime placement
adds a free joint and lays the object horizontally on the classroom desk.
