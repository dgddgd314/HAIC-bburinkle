# Square pencil holder source

The visual is converted from the user-provided `pencil_holder_square/pencil_holder.obj`. The source is Y-up; the conversion rotates the opening upward and scales it to 13 x 13 x 15 cm.

The source archive did not include license information. Confirm the original model's redistribution terms before sharing the mesh outside this project. Collision is an open box made from one bottom and four walls; the cavity is not filled.
