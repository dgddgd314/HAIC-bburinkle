# M4 방 인식과 교실 진입 실험

2026년 11월 28일, ROS 2 Humble과 MuJoCo에서 4시간 2분 30초 동안 독립 주행 77회를 실시했다. 각 주행에서 G1이 세 문 앞에서 찍은 RGB 사진을 저장해, 기본 모델과 기존 학습 모델에 동일한 새 사진 231장을 입력했다. 교실 진입은 실제 주행을 제어한 모델별로 공식 채점기의 골반 위치 판정을 집계했다.

| 모델 | 새 사진 231장 | 추가 학습 후 촬영한 공통 159장 | 교실 진입 |
|---|---:|---:|---:|
| PaliGemma 2 기본 | 208/231 (90.0%) | 140/159 (88.1%) | 30/30 |
| 기존 학습 모델 | 231/231 (100%) | 159/159 (100%) | 30/30 |
| 추가 학습 모델 | 초기 72장을 추가 학습에 사용 | 159/159 (100%) | 17/17 |

기본 모델의 오답 23장은 모두 식당을 교실로 판단한 경우였다. 세 방에 서로 다른 이름을 배정하면 기본 모델도 77개 배치 모두 맞혔다. 기본·기존 학습 모델은 여섯 방 배치를 각각 5번씩 주행했다. 추가 학습 모델은 각 배치를 2~3회 주행했다. 리스폰은 총 0회였다. 이 실험은 M4 단독 실행이며 대회 웹 플래너를 포함한 연속 미션은 별도의 검증 대상이다.

## 공유 모델 실행

배포 후보는 기존 학습 모델이다. 최초 학습에서 독립 실행 10개의 사진 30장으로 시각 프로젝터를 3에폭 학습했다. 추가 학습에는 기존 30장과 새 72장을 사용했으며, 이후의 공통 159장에서 두 학습 모델이 동률이었다.

팀이 별도로 제공하는 `M4-projector-231of231.zip`을 풀고 다음 명령을 저장소 루트에서 실행한다. Google의 `google/paligemma2-3b-mix-224` 리비전 `8e40ab4cc5df93dfb7fd2fff754bcdff8b62ee78`의 전체 로컬 스냅샷과 프로세서가 필요하다. 실험에는 Transformers 4.53.3과 CUDA PyTorch를 사용했다.

```bash
python server/mission_4/vlm_server.py /path/to/original/snapshot \
  --projector /path/to/unpacked/projector.safetensors --host 127.0.0.1 --port 8044
```

이 명령은 팀 서버의 루프백 주소에서 수신한다. 시뮬레이터 PC에서 SSH 터널로 연결하거나 팀 네트워크에 맞게 바인딩 주소와 `M4_VLM_URL`을 지정한다. 팀 서버에 이미 있는 전체 학습 체크포인트를 사용할 때는 해당 디렉터리를 첫 인자로 전달하고 `--projector`를 생략한다.

### 팀원별 실행 순서

1. **추론 서버 담당자**는 팀 저장소의 `feat/mission-4` 브랜치를 준비한다. 연습용 추론 서버에 위 리비전의 기본 모델 전체와 팀 프로젝터 ZIP을 직접 전송한다. ZIP의 SHA256은 `57dd8c5e2bb76e94e920fe5685cdbe815127171615f99b192e9992c12d937837`이다. 압축을 푼 폴더에서 `sha256sum -c SHA256SUMS`로 내용을 확인한 뒤 위 명령으로 서버를 시작한다. 학습 전용 H100은 가중치 학습에 사용한다.
2. **시뮬레이터 담당자**는 같은 브랜치를 준비한다. 아래 첫 명령의 `USER@INFERENCE_HOST`를 연습용 추론 서버의 SSH 접속 정보로 바꾸고 터널을 열어 둔다. 두 번째 터미널에서는 HAIC 환경을 활성화하고 저장소 루트에서 JPEG 요청과 M4를 실행한다.

```bash
# 시뮬레이터 PC의 첫 번째 터미널
ssh -o ExitOnForwardFailure=yes -N -L 127.0.0.1:8044:127.0.0.1:8044 USER@INFERENCE_HOST
```

```bash
# 시뮬레이터 PC의 두 번째 터미널
export M4_VLM_URL=http://127.0.0.1:8044/scores
curl --fail-with-body -H 'Content-Type: image/jpeg' \
  --data-binary @server/mission_4/examples/cafeteria.jpg "$M4_VLM_URL"
(cd src && python main.py --missions 4)
```

샘플은 주행 `r01-p1-base`의 중간 문에서 촬영한 식당이다. JSON에는 `classroom`, `medical`, `cafeteria` 세 점수가 있어야 한다. 같은 사진에서 기본 모델은 교실, 배포 후보는 식당에 최고점을 줬으므로 프로젝터 적용 여부를 점검하는 데 사용할 수 있다.

### 남은 통합 검증

- 최종 연습용 추론 서버에서 모델 경로와 접속 방식을 확정하고, 실제 시뮬레이터 PC에서 위 JPEG 요청과 공식 M4 단독 채점을 확인한다.
- 팀 통합 브랜치에 M4를 반영한 뒤 `python main.py --llm-web`에서 앞뒤 미션을 포함한 순서로 실행한다. M4 진입 위치, 북→중간→남 반환값과 교실 내부 골반 판정을 확인한다.
- 77회 주행에서 리스폰은 0회였다. 리스폰 복구는 연습에서 별도로 발생시켜 이전 배치의 점수를 버리고 세 문을 다시 관측하는지 확인한다.
